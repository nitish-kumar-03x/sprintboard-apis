Features
 
Authentication
- User Signup and Login using JWT authentication
- Password hashing using bcrypt
 
Projects (CRUD)
- Create a project
- Get all projects
- Update a project
- Delete a project
 
Tasks (CRUD)
- Add a task (Create)
- Get all tasks (Read)
- Get a single task
- Update a task (especially status update)
- Delete a task
 
Fields (Task)
- Title
- Description
- Status:
  todo
  in-progress
  done
 
Advanced Features
- Filter tasks by status
- Search tasks by title
- Pagination (limit and page)
 
What You’ll Learn
- JWT authentication and bcrypt
- Middleware reuse across projects
- MongoDB schema design (User → Projects → Tasks)
- CRUD APIs with multi-level relationships
- Querying with filtering and pagination
